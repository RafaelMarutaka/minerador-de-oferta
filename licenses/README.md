# Licenças de componentes

Partes deste projeto vêm de componentes de código aberto. As licenças deles pedem que o aviso original acompanhe o código, então os avisos ficam guardados aqui:

| Arquivo | Vale pra |
|---|---|
| `MIT-componente-anuncios.txt` | leitura da Biblioteca de Anúncios em `src/` |
| `Apache-2.0-componente-nucleo.txt` e `NOTICE-componente-nucleo.txt` | `packages/nucleo/`, renomeado e modificado |

Dependências instaladas pelo npm (`@modelcontextprotocol/server`, `zod`, `playwright`) trazem as licenças delas dentro de `node_modules`.
